# redstone-site-builder

A Claude Code skill that orchestrates building a premium client website. It routes each stage (intake, planning, build, polish, verify) to the right installed skill or tool, with three approval gates.

## Install

Copy this folder to `~/.claude/skills/redstone-site-builder/`.

It relies on other skills being installed: Superpowers, Impeccable, and the motion/polish skills named in `SKILL.md`.
